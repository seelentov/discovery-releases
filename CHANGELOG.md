# Changelog

## v1.1.1 — 2026-09-23

Patch release: 23 исправления и security-патча после v1.1.0 — устойчивость очередей и
уведомлений, сохранность syslog/trap при нагрузке, корректные тревоги и topology, защита
runtime-конфигурации и devicefarm, восстановление E2E/bootstrap и совместимость миграций.

## v1.1.0 — 2026-09-23

Обновление после v1.0.0: исправления безопасности webhook secret, валидации retention,
массового включения устройств по выборке и восстановление активных тревог после рестарта.
Артефакты опубликованы для macOS, Windows и Linux (arm64/x86_64; `.deb` и `.rpm`).

## v1.0.0 — 2026-09-18

Первый официальный стабильный релиз. Автодискаверинг устройств по SNMP, опрос метрик
(SNMP v1/v2c/v3 + push-приём SNMP Trap/Syslog + SSH CLI-метрики), тревоги с гистерезисом,
топология и подавление вторичных тревог, уведомления (email/Telegram/webhook) с матрицей
адресации, веб-дашборд, ролевой доступ. Самостоятельный пробный период — 3 дня, без
отдельной активации.

Впервые доступны готовые бинарники под все три ОС без исходного кода: macOS
(arm64/x86_64), Windows (x86_64), Linux (x86_64/arm64 — `.deb` и `.rpm`).

## v0.1.0 — внутренние тестовые сборки

Сборки `.deb`/`.rpm` (только Linux) из ранней стадии разработки — использовались для
живой проверки пакетной установки на реальном systemd (Debian 12, Fedora 40), не
предназначались для публичного распространения. Оставлены для истории. Для реального
использования — берите v1.0.0.
